# GuessNumberApp 🔢 (React Native Application)

**GuessNumberApp** is a simple and interactive mobile application built with **React Native**, where the app tries to guess the number you’re thinking of — and you help it get there with hints! 🎯

This project was created as part of my journey to learn **React Native**, improve my programming logic, and gain hands-on experience with mobile development.

---

## 🚀 Features

- 🔢 **Interactive Gameplay** – Think of a number, and let the app guess it based on your feedback.
- 🎯 **Smart Guessing Logic** – Implements binary search-style logic to efficiently find your number.
- 📱 **Cross-Platform UI** – Designed for both iOS and Android devices.
- 💡 **Clean User Interface** – Simple and intuitive design for a smooth user experience.
- 🔄 **Game Restart Option** – Easily play multiple rounds.

---

## 🛠️ Technologies Used

- **React Native** (Expo)
- **React Hooks** (`useState`, `useEffect`)
- **Expo CLI** for development and testing
- **JavaScript (ES6+)**
- **Custom Styles** with `StyleSheet` and conditional rendering

## 📂 How to Run the App

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/GuessNumberApp-React-Native-Application.git
   cd GuessNumberApp-React-Native-Application
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the app:
   ```bash
   npx expo start
   ```

4. Scan the QR code using the **Expo Go** app on your mobile device.
